# ChurnAI

Customer churn prediction platform: Python/Flask backend, Next.js frontend, SQLite database, ML churn model.

## Status

Project foundation only. Backend, frontend, ML, and database code have not been created yet — build phase-by-phase.

## Rules

- Keep changes minimal and scoped to the current phase. Do not scaffold future phases early.
- No dependencies are installed yet. Do not add packages until the relevant phase begins.
- Backend lives under `backend/`, frontend under `frontend/`, ML code under `ml/` (once created).
- Never commit `.env` files, secrets, or SQLite database files.
- Keep commits small and phase-scoped.
